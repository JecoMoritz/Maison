TUGAS HYPERLINK HTML + CSS

File:
- home.html
- about.html
- profil.html
- kontak.html
- galery.html
- style.css

Cara menjalankan:
1. Ekstrak folder.
2. Pastikan semua file berada dalam folder yang sama.
3. Buka home.html menggunakan browser.
4. Klik menu Home, About, Profil, Kontak, dan Gallery untuk menguji relative link.
5. Link Google menguji absolute link.
6. Bagian "Pengenalan" pada home.html menguji anchor link.
7. Link email pada Home/Kontak menguji email hyperlink.

Catatan:
CSS menggunakan file eksternal style.css agar semua halaman memakai desain yang sama.
