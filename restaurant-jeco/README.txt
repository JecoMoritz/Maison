MAISON SEREIN - RESTAURANT WEBSITE

File:
1. index.html  -> struktur halaman
2. style.css   -> desain/tampilan
3. script.js   -> filter menu, modal video, dan form reservasi demo

Cara menjalankan:
- Simpan ketiga file dalam satu folder.
- Buka index.html di browser.
- Untuk GitHub Pages/Vercel, upload ketiga file tersebut sebagai satu project.

Catatan:
- Gambar menggunakan URL Unsplash agar langsung tampil saat online.
- Video di Gallery memakai video demo W3Schools dan bisa diganti dengan video sendiri.
- Nama restoran, alamat, harga, dan menu dapat disesuaikan dengan tugas dosen.
